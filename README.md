# pTumblerMini - an Open Source Part Tumbler
This part tumbler was originally designed in a speed run. The total time it took was: 9 hours and 24 minutes.

pTumbler Mini is a smaller, desktop version of the tumbler developed after the initial speedrun.

pTumbler MiniCNC is a version of the Mini that can be CNC Milled or 3D printed


## SAFETY NOTICE
These tumblers operate at noise levels that are unsafe for extended periods. Hearing protection gear must be used according to OSHA standards when operating this equipment.
